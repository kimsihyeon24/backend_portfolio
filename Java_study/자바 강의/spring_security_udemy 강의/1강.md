기억에 남는 것

application properties에 스프링 시큐리티에서 제공하는 username, password를
직접 입력해 효율적인 개발 환경 세팅 -> 항상 완벽한 로직 생성하고 하는 것 아님
개발 시기 효율을 위해 간단한 시큐리티 생성 가능

또한 로그마다 나타내는 정보에 색을 입혀 에러 또는 작동 과정 눈에 쉽게 보이게 만듦



핵심

1. 맨처음 아무 설정 없이 spring security를 실행할 때

8080 포트 진입시 authorizationfilter()에서 에러 발생시켜 기본 제공

로그인 html이 있는 곳으로 이동 이것이 default 머시기임 



2\. 페이지에 id, password 입력시 

abstractAuthenticationProcessingFilter()은 usernamePassordAuthenticationFilter

여기서 attemptAuthentication을 이용해 사용자 입력 객체를 가져옴
일단 객체는 가지고 인증은 false라는 값을 가지고 시작
그리고 providerManager로 이동

여기서 여러 인증 방법을 for문을 통해 검증하는데
초기설정에는 InmemoryUserDetailsManager와 passwordEncoder를 이용해 객체를 인증한다.
그리고 결과에 따라 역으로 이동하면서초기 인증 객체를 true로 만들고 반환한다.
