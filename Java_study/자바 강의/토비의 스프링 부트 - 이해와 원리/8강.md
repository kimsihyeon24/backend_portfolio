autoconfiguration에 대해 이야기를함

autoconfiguration으로 스프링 부트에 필요한 라이브러리들을 자동으로 어노테이션 안에서

정리를 하는데 configuration을 사용해서 내가 원하는 라이브러리를 상황에 따라

사용할 수 있음을 알려준 강의



솔직히 내 범위를 크게 넘어선 범위가 아닌가라는 생각이 드는 강의였다.

왜냐하면 아직 라이브러리가 뭐가 있는지도 자세히 모르고 그저 autoconfiguration에

의존하면서 개발을 하고 있었는데, 하나씩 설정할수있다니 크게 의미가 있는지 모르겠었다.

하지만 개발 세상은 변화하는 만큼 필요한 라이브러리를 적절하게 사용하는 역량을 가지게 된다면 가치가 높아질 것이라는 생각을 가졌다.

후에 필요성을 느낀다면 학습을 다시해야겠다.
