spring boot를 활용해 코드를 작성하는 과정에서 servlet을 생성하고 작성할 이유가 없어짐

그래서 직점 구현해보는 과정을 거침

기억나는 거는 톰캣을 생성 -> servlet컨테이너 생성

이것을 매핑하고, 그안에 서블릿을 생성해서 http 생성하고, 로직 작성함

이때 여러 경로를 통해 오는 것을 한번에 매핑하고 싶었음

왜냐하면 똑같은 로직을 여러번 작성해야하니 유지보수 측면에서 어려웠음

그래서 프론트 매핑이라는 것을 추가해 경로를 추가하고 -> requestMapping과 유사

이것을 if else 문으로 또 각 요청경로와 GET, POST 등 에 따라 나누는 로직을 짬
