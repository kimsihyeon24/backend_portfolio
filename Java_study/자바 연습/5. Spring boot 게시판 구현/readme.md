기본적으로 백엔드와 db과 연결되는 코드를 작성할 필요가 전혀 없었고,

추상적인 틀만 작성하면 되어서 service코드에 집중할 수 있게 된 것 같다.

물론 html파일의 대부분은 ai를 활용하여 했다. 아쉽긴하지만 학습의 효율성을 위해 택했다.

또한 db도 생성해주고, 필요한 메서드들은 미리 준비해주고 특히 update를 할때 수정후 혼자서 save 메서드를 불러와 저장한다는 것을 알고 정말 잘 만들었구나 라는 생각을 했다.

하지만 복잡한 로직을 구현할 때는 위험할 수 있겠다라는 생각을 했다.

또한 간단한 crud 작업이기에 아직은 JPA의 마법에 매료됐지만 나중에 동시성을 처리하는 작업에서는 문제를 맞을 수 있겠다는 생각을 했다.
